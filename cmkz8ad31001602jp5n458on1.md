## 2\. What is HTML and Why Do We Use It?

HTML stands for **HyperText Markup Language**. This term is very important to understand. HTML is a way to share documents that are connected to other documents using links. It allows content to be structured in a way that supports navigation, links, images, media, and various formats, all inside a single document.

With the help of HTML, browsers can quickly understand and display content in a structured manner. HTML makes it easy to present both the content and its meaning so that browsers can interpret it correctly.

In earlier times, people did not send complex documents with structured data over the internet. In 1989, the need arose to share scientific documents that were complex and interconnected. To solve this problem, **Tim Berners-Lee** proposed a solution called HTML, which stands for HyperText Markup Language.

To share HTML files over a network, he also proposed a way for computers to request and receive these documents. For this, he introduced the concept of **URLs**, which are used to identify specific resources on the internet. Along with this, he also proposed a protocol called **HTTP**, which stands for HyperText Transfer Protocol.

HTML and HTTP are closely related. HTML defines how content is structured, while HTTP defines how that content is transferred over the internet. HTTP is the protocol used to transfer HTML data from a server to a browser. Even today, modern websites are fetched using HTTP requests, following the same basic idea proposed by Tim Berners-Lee.

Although modern websites include design using CSS and functionality using JavaScript, the core of every website is still HTML, and it is still delivered using HTTP.

## 3\. What is an HTML Tag?

An HTML tag is a special instruction written inside angular brackets (`< >`). Once text is written inside these brackets, it is no longer considered normal text. Instead, it gains a specific meaning that the browser understands.

For example, HTML opening tags `<html>`, HTML closing tags `</html>`, body opening tags `<body>`, and body closing tags `</body>` are not just words. Each of these tags has a specific role, behavior, and meaning that tells the browser how to interpret and display content.

HTML tags follow a simple convention: an opening tag, a closing tag, and the content inside them. The opening tag tells the browser to start applying a rule, and the closing tag tells the browser to stop that behavior. In simple words, a tag adds meaning to the content written inside it.

## 4\. Understanding How Tags Change Meaning

Let’s understand this with a simple example. Suppose you write the text **“My name is Khalid”** inside the `<body>My name is Khalid </body>` tag.

Now write the same text inside a `<p>My name is Khalid</p>` tag, and then inside an `<h1>My name is Khalid<h1>` tag.

`<body>My name is Khalid </body>`

`<p>My name is Khalid</p>`

`<h1>My name is Khalid<h1>`

In all cases, the text content is exactly the same.

However, for the browser, these are completely different things. The browser does not just read the English meaning; it reads the tag and assigns meaning based on it. Text inside a body tag, a paragraph tag, and a heading tag all have different roles and display behaviors.

For humans, the sentence remains the same, but for the browser, the meaning changes entirely. This is why we need a structured grammar like HTML—to help computers understand content and present it correctly to humans.

## 5\. What is an HTML Element?

An HTML element consists of three parts: the tag, the content, and the complete element itself.

The tag includes the opening and closing tags, such as `<p>` and `</p>`. The content is the text written inside the tags, for example, **“Hello Reader, how are you?”**. The element is the combination of the opening tag, the content, and the closing tag together.

## 6\. Self-Closing and Void Elements

Some HTML elements do not require any content at all. These are called **self-closing elements** or **void elements**. Void elements cannot contain text, cannot have child elements, and cannot wrap any content.

This is not a mistake or a limitation—it is a design choice in the HTML language. These elements exist to attach specific meaning or behavior without needing any content inside them. If you are curious about why such tags exist, it is recommended to explore their purpose in more depth through further research.

Some examples are : `<a>, <hr> <br> <img> <strong>`

## 7\. Block-Level Elements vs Inline Elements

Understanding the difference between block-level elements and inline elements is extremely important, especially when working with CSS. Many CSS behaviors are directly influenced by how HTML elements behave by default.

Block-level elements occupy the entire width of the line in which they are written. No other element—whether block-level or inline—can appear on the same line. These elements always start on a new line and take up all available horizontal space.

Inline elements behave in the opposite way. They only take up the space required by their content and allow other elements to occupy the remaining space on the same line. However, block-level elements will never share a line, even if there appears to be space available.

You can think of block-level elements as elements that want full control of the line, forcing everything else to move to the next line. Inline elements are more flexible and cooperative, allowing multiple elements to appear together.

## Examples of Block and Inline Elements

Block-level elements include elements like `<div>`, `<p>`, `<h1>…<h6>`, `<section>`, `<main>`, `<article>`, `<aside>`  
Inline elements include elements like `span`, `strong`, and `em`.

These examples help illustrate how different elements behave in terms of layout and space usage.

## 8\. How Many HTML Elements Are Actually Used?

As of HTML5, there are more than 120 HTML elements available. However, in real-world development, only about 25 to 30 elements are commonly used across most websites.

In practical projects, even large websites often rely on a small subset of HTML elements. In one of our projects of chaicode.com web dev cohort, we used only limited tags.

Typically, a document starts with the `head`, `title`, and `body` tags. Inside the body, the page is usually divided into three main sections: header, main content, and footer. Inside the header, we often use heading tags and paragraphs to provide context. Inside the main section, elements such as sections, articles, paragraphs, links, lists, and form elements are used. Inside the footer, additional informational or navigational content is placed.

Most real-world websites rely on a limited set of well-understood HTML elements. Deep understanding of these commonly used elements is far more important than memorizing every available tag. Proper usage also improves accessibility, structure, and overall quality of web pages.
